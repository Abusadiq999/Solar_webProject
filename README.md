# Solara Energy website
A responsive website for a Nigerian solar installation and maintenance company.
Open `index.html` in a browser, or run `python -m http.server 8000` and visit `http://localhost:8000`.
It uses HTML, CSS, and JavaScript, with no database or build step.
The contact section and footer include the current phone number, email, and office address. Before publishing, replace the sample logo, images, and social links; connect the enquiry form to a service because it does not send messages yet.
